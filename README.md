# 海湾入境团队服务编排

面向海湾国家家庭独立团（示例：迪拜八口家庭单独赴重庆）的团队编排服务。
运营人员在订机酒之外，需要同时锁定家庭房、清真餐饮、语言、无障碍与
城市接驳，且任一供应商更换都不能破坏整套安排。本仓库把这些约束固化
为领域模型与可执行规则。

## 领域模型

| 模块 | 职责 |
| --- | --- |
| `src/members.py` | 证件令牌（只存脱敏指纹 `P****2471`，退出即吊销）、成员、亲属关系图（户主/配偶/子女/父母/兄弟姐妹） |
| `src/units.py` | 五类预订单元（航班座位、酒店房间、包车、景点场次、当地服务人员）与保持策略 |
| `src/capabilities.py` | 城市服务能力目录与能力标签（清真厨房、家庭房、礼拜朝向、轮椅、阿语员工、接机……） |
| `src/itinerary.py` | 带 IANA 时区的共享行程，zh/ar/en 同构渲染，航班延误 SHIFT/NOTIFY 级联 |
| `src/money.py` | 最小单位整数金额、汇率快照、多币种定金台账（定金/退款/没收） |
| `src/lifecycle.py` | 咨询 → 确认 → 入境 → 消费 → 复访 五阶段及合法迁移 |
| `src/disclosure.py` | 合作方最小信息披露（按角色 × 阶段下发字段） |
| `src/orchestrator.py` | 编排聚合：能力匹配、原子换商、退出结算、跨境取消、延误、披露 |

供应商），`fixtures/dubai_family.json` 是不含真实个人信息的迪拜八口
家庭：户主夫妇、三名子女、一位轮椅长辈、一名婴儿，全员清真、阿语为主。

## 核心规则

### 成员退出：只释放自己的占用

- 航班座位、普通景点票是 `INDIVIDUAL` 单元：退出释放该成员自己的席位；
- 家庭房、包车、随团导游/餐饮是 `GROUP_LOCKED` 单元：只摘除成员个人
  占用，**锁定容量与单元状态不变**——不拆房、不换小车、不退其他成员；
- 令牌随退出吊销；户主退出时按 配偶 → 成年子女 → 父母 顺序转移户主；
- 个人席位定金按原币种退还其人均份额，锁定单元费用不拆退。

### 供应商更换：原子且能力不减弱

`swap_supplier` 在一个事务内完成“旧单元取消 + 新单元确认”：占用成员、
锁定容量、单元状态整体迁移；新供应商必须同城市、同类型、能力标签为
旧选项超集、容量不低于锁定容量，任一不满足则整体回滚。入境后禁止换商。

### 航班延误：时区感知的接驳级联

行程时间以 UTC 存储、按发生地 IANA 时区渲染。航班（`SHIFT`）延误后，
接机包车按最小入境间隔自动顺延；酒店入住等 `NOTIFY` 项只通知不改时间。
三语视图的编号、起止时刻严格一致，只有文案本地化。

### 多币种定金与跨境取消

定金按币种分账（AED/CNY/USD），禁止无汇率快照的跨币种轧差；汇率在
报价时固定为 `FxQuote` 快照。跨境取消逐单元比对免费时限：免费取消
原路全退，超时按条款没收违约金后退还余款；已入境不适用跨境取消。

### 最小信息披露

| 阶段 | 合作方可见 |
| --- | --- |
| 咨询 | 仅需求摘要（人数、清真/无障碍/语言） |
| 确认 | 需求摘要 + 本单元脱敏成员码；证件指纹**仅航司**可见 |
| 入境 | 增加到达时间窗（仅接机/航司） |
| 消费 | 核销码 |
| 复访 | 仅偏好摘要 |

合作方只能查看自己履约的单元；视图中永远没有真实姓名、证件号、其他
成员或其他供应商安排。

### 五阶段运营视图

咨询（询价占位）→ 确认（定金到账、整包能力校验）→ 入境（通关履约、
延误处理）→ 消费（核销结算）→ 复访（留存偏好，可直接发起新咨询）。
阶段不可跳跃，全部迁移留痕。
