# 海湾入境团队服务编排

面向海湾游客（样例：迪拜八口之家独立成团赴重庆）的团队编排领域模型与服务。
运营人员在确认机酒之外，必须同时闭环 **家庭房、清真餐饮、语言、无障碍、城市接驳** 五类约束；
系统保证供应商更换不破坏整套安排，成员退出不拆散家庭房与包车。

## 领域规则

1. **证件令牌 + 亲属关系维护成员**：成员只持有 `token_ref` 令牌，证件号仅留掩码；
   亲属边描述家庭结构，家庭房按房单（family unit）整体锁定。
2. **带时区的共享行程**：所有事件保存时区感知的绝对时刻；航段按出发地/到达地双时区渲染
   （DXB `Asia/Dubai` → CKG `Asia/Shanghai`），境内活动统一北京时间。
   客人看到中/阿/英三语行程，文案不同而时刻指纹完全一致。
3. **锁定单元不可拆分**：家庭房（`ROOM:<unit>`，不可拆）、团队包车与向导（`TEAM`，不可拆）、
   个人座位/餐位/门票（`PERSON`，可按人释放）。成员退出只释放本人的 PERSON 占用，
   家庭房按原房单保留、包车不按人数重算。
4. **供应商原子更换**：同一服务的全部锁整体迁移；新供应商必须同时满足清真、无障碍、
   语言、容量等全部约束，任一失败即整单回滚。
5. **多币种定金与跨境取消**：航班以 AED 报价、境内服务以 CNY 报价；定金统一按 AED 收取
   并冻结汇率快照。取消分档退款（30/14/7 天），退款一律按收款币种 AED 与原汇率；
   承运人责任全额退；成员退出后整团取消不重复退款。
6. **航班延误传播**：去程航班为锚点事件，延误超过 90 分钟自动顺延接机礼宾与包车；
   首晚餐饮赶不上餐厅截单时，自动转为深夜清真餐盒并退回餐费。
7. **合作方最小信息披露**：按服务类别下发不同字段——航班拿令牌引用与哈希、
   酒店只拿本房单化名名单、包车/餐厅/景点只拿人数与轮椅数；亲属关系与证件号绝不出系统。
8. **五阶段区分**：咨询 inquiry → 确认 confirmed → 入境 inbound → 消费 in_destination → 复访 revisit，
   非法跃迁被拒绝。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `fixtures/team.json` | 脱敏八口团队：成员、令牌引用、亲属边、家庭房单、包车需求 |
| `fixtures/credentials.json` | 证件令牌登记（掩码证件号 + 演示哈希，全部虚构） |
| `fixtures/city_services.json` | 重庆服务能力：航班/酒店房型/包车/清真餐厅/无障碍景点/阿语向导/接机礼宾，多币种报价 |
| `fixtures/fx_rates.json` | 演示汇率（AED/CNY/USD/SAR） |
| `fixtures/policies.json` | 定金、跨境取消分档、延误阈值、五阶段、最小披露矩阵 |
| `contracts/*.schema.json` | 上述资料的 JSON Schema 契约 |
| `src/context.py` | 基础领域资料读取（原有） |
| `src/orchestration/` | 编排模型：`members` / `money` / `catalog` / `itinerary` / `ledger` / `disclosure` / `engine` |
| `tests/test_orchestration.py` | 34 个端到端用例 |
| `demo.py` | 八口之家完整编排演示 |

## 运行

```bash
python3 -m unittest discover -s tests   # 全部测试
python3 demo.py                         # 完整编排演示
```

## 已记录的业务事实

- 海湾国家游客赴华数量明显增长
- 游客可能提出家庭独立组团需求
- 旅游合作强调便利化和本地化服务

所有姓名、证件号、供应商与报价均为虚构样例，不含账号、凭据或真实主体信息。
